# 示範素材

2026 年 9 月 17 日從公開版的空白本機資料庫與乾淨瀏覽器實際擷取

使用 `data/example/demo.json` 的 120 段虛構航班，涵蓋五年、20 個國家／地區與六洲。沒有使用個人旅行紀錄

| 素材 | 實際來源 |
| --- | --- |
| world-map.png | 1440 × 1000 桌面旅行地圖，顯示完整示範統計 |
| mobile-map.png | 390 × 844 手機旅行地圖，顯示匯入及清空入口 |
| journey.png | 1280 × 800 旅程放映，EK261 杜拜至聖保羅，日期虛構 |
| journey.gif | 同一航段連續 8 秒的實際錄影，以 1 倍速回放，6 fps、720px 寬輸出 |
| passport.png | 從網頁「儲存護照圖片」實際下載的 PNG，保留虛構示範標記 |

截圖沒有額外繪製 UI，GIF 沒有加速或以靜態畫面模擬飛行。網站實際動畫不受 GIF 幀率限制

README 的桌面地圖與放映素材展開右下角圖資署名。NASA GIBS、OpenFreeMap、OpenMapTiles、OpenStreetMap 與護照使用的 Natural Earth 說明見根目錄 THIRD_PARTY_NOTICES.md
