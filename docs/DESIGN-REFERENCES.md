## 實作方向

**個人航線卡**：深色展示背景（#101827）、淡青與淡紫卡紙（#cbe5ed）、紫墨航線（#372665）。採用 Natural Earth 真實地理輪廓，疊上已搭乘航線；年份與里程均由紀錄計算。操作介面沿用系統字，日期使用等寬數字。卡片可匯出為 PNG。

**地球底圖**：MapLibre 地球投影搭配 NASA GIBS Blue Marble 全球地表合成影像，免 API key；平面視角沿用 OpenFreeMap。這不是即時衛星影像或 Apple Maps，來源與授權見 `THIRD_PARTY_NOTICES.md`。

- 保留：已搭乘數、估算里程、年份、國家、實際航班資料、可回放航線。
- 替換：深藍仿護照封面與章格改成航線卡及可點選的抵達紀錄；密集桌面側欄改為可收起。
- 標明限制：首次是「目前紀錄中的首次」，抵達可能包括轉機；抵達紀錄不代表出入境證明。
- 航班點選立即開始回放；時間插值大部分採線性，少量平滑處理，減少開頭停滯。減少動態設定保留靜態狀態。
- 收藏航班和抵達紀錄都是按鈕，點選會關閉護照並定位該航線。年份使用原生選單；手機關閉列固定在頂部。

## 元件是否真的有幫助

| 元件       | 使用條件                           | 避免的做法                         |
| ---------- | ---------------------------------- | ---------------------------------- |
| 可收合側欄 | 需要查找時展開；收起後地圖重新取景 | 隱藏後仍替不可見面板預留地圖空間   |
| 航線回放   | 用來回想一趟旅程，且可重播／中断   | 假裝即時航跡、長時間等待才看到飛機 |
| 票根       | 用真實機場、日期、班號建立記憶     | 為了裝飾捏造座位、登機門、條碼     |
| 抵達紀錄   | 聚合國家且能連回來源航班           | 沒有操作的圖示堆疊、虛構入境證明   |
| 年份選擇   | 所有統計和票根都使用同一篩選       | 只改標題但仍顯示累計數字           |

Flighty 是設計參考，不是本專案的素材或程式來源。本專案沒有重製其品牌、畫面圖片或專有服務。
